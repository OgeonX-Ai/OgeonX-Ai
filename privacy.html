Privacy Policy for Kim Career Automation

Last updated: 30 June 2026

1. Controller and contact

Kim Career Automation is a personal application operated by Kim Harjamäki / OgeonX AI. For privacy questions or deletion requests, contact: ogeonx@gmail.com.

2. Purpose of the application

The application is used for professional career automation, LinkedIn authentication testing, and related cloud and AI integration experiments. It may be used to support secure OAuth sign-in, profile handling, job-search workflows, and career-related automation owned by the controller.

3. Data collected

The application may process the following data only when authorized or provided by the user:

  • Basic LinkedIn profile information, if authorized by the user.
  • Email address, if authorized by the user.
  • OAuth authentication metadata required for login, security, and debugging.
  • Career-automation or job-search metadata, such as role title, company, application status, and notes, when explicitly used by the owner.

4. How data is used

Data is used to authenticate the user, test integrations, support career automation workflows, improve reliability, and troubleshoot technical issues. The application does not use personal data for advertising or unrelated profiling.

5. Data sharing

The application does not sell personal data. The application does not share personal data with advertisers. Data may be processed by infrastructure or API providers only as required to operate the application and integrations.

6. Posting and messaging

The application does not post publicly, send messages, or submit external actions without user action or explicit automation rules configured by the owner.

7. Data retention

Data is stored only as long as needed for testing, automation, debugging, security, or legal obligations. Test data may be deleted when it is no longer needed.

8. Security

Reasonable technical and organizational measures are used to protect data, including least-privilege access, OAuth-based authentication, and secure handling of credentials and secrets.

9. User rights

A user may request access, correction, or deletion of their personal data by contacting ogeonx@gmail.com.

10. Changes

This policy may be updated when the application, integrations, or data processing practices change. The latest version will be published at this URL.
